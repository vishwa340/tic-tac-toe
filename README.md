# Tic Tac Toe 🎮

A simple Tic Tac Toe game built using HTML, CSS and JavaScript.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ✨ Features

- Two-player game
- Win detection
- Draw detection
- Reset game button

## 🚀 How to Play

Open `index.html` in your browser and start playing.
